# 離子麻將 (Ion Mahjong Online) - 多人連線房間版

本專案為將單機版《離子麻將》完整改裝的「房號制多人即時連線對戰」網頁遊戲。採用權威伺服器架構（Authoritative Server），由後端統一管理牌庫與判定，並透過 Socket.io 提供安全手牌私密性、出牌倒數計時、測試機器人、行動端 RWD 縮放與化學沉澱加番。

---

## 快速啟動指南（在您的電腦上執行）

### 1. 安裝環境需求
* 請先安裝 **[Node.js](https://nodejs.org/)** (建議 v18 或以上版本)。

### 2. 安裝依賴套件
解壓縮專案資料夾後，打開終端機（Terminal 或 PowerShell / CMD），進入此目錄並執行：
```bash
npm install
```

### 3. 啟動伺服器
```bash
npm start
```
終端機會顯示：
```text
離子麻將多人伺服器已啟動於 port 3000
```

可在瀏覽器開啟 `http://localhost:3000/health`；若看到 `{ "ok": true }`，代表伺服器已成功啟動。

### 4. 執行規則測試
```bash
npm test
```
此命令會驗證牌庫、電中性、吃牌、胡牌與化學加分的核心規則。多人流程仍須依下方清單做實機驗收。

### 5. 本地遊玩與測試
打開瀏覽器網址輸入：
👉 **http://localhost:3000**

* **單人除錯測試**：
  1. 輸入暱稱點擊「建立新房間」。
  2. 進入等待室後，房主可直接點擊「🤖 加入測試機器人」補齊 3 位虛擬玩家。
  3. 滿 4 人後點擊「🚀 開始遊戲」，單一瀏覽器即可測試摸牌、出牌、吃牌、胡牌與計分結算！
* **多人連線測試**：
  開啟多個分頁或無痕視窗，輸入相同的 6 位數房號即可同桌對戰。

## 免費雲端部署（讓朋友/學生從外網直接連線）

以免費又支援 WebSocket 的 **[Render.com](https://render.com/)** 為例：

1. 將本專案上傳至您的 **GitHub**（建立一個新的 Repository）。
2. 前往 **Render.com** 註冊並點擊 **New +** ➔ **Web Service**。
3. 連結剛建立的 GitHub Repository。
4. 設定參數：
   * **Runtime**：`Node`
   * **Build Command**：`npm install`
   * **Start Command**：`node server.js`
   * **Instance Type**：`Free`
   * **Environment Variable**：`CLIENT_ORIGIN=https://你的正式網域`
5. 點擊 **Create Web Service**，等待 2～3 分鐘部署完成。
6. Render 會提供一組專屬網址（例如 `https://ion-mahjong.onrender.com`）。
7. 將網址發給朋友，或者在遊戲內點擊「🔗 複製邀請連結」，對方點開即可自動帶入房號進房暢玩！

> 本機測試時不必設定 `CLIENT_ORIGIN`。部署到雲端時務必設定為正式 HTTPS 網域（多個網域可用逗號分隔），不要維持萬用跨來源設定。

## 上線前多人流程驗收

部署前至少以四個獨立瀏覽器 session（或一位真人加三個 Bot）完成以下測試：

1. 第一局自摸、放槍胡牌與流局都會立即顯示本局結算、化學加成與即時排名。
2. 房主按「開始下一局」後，分數保留、直接進入下一局，不回等待室。
3. 第四局結束或任一玩家分數小於等於 0 時，顯示最終排名；只有房主可重新開始四局賽。
4. 非房主點擊結算按鈕不會推進局數；房主斷線後依遊戲內規則驗證行為。
5. 用手機測試結算視窗、行動按鈕與橫向畫面不被裁切。

## 核心亮點與特色

1. **防作弊手牌私密性**：每位玩家只能收到自己的 12～13 張明牌，其他三家僅同步蓋牌張數與外露組合。
2. **防掛機出牌計時器**：摸牌按鈕限時 10 秒；摸牌後與吃牌後均給 45 秒思考及出牌。逾時才由伺服器自動出牌；吃／胡裁決窗口為 25 秒，讓玩家有足夠時間選擇組合。
3. **手牌拖曳排序**：桌面瀏覽器可拖曳手牌到任意位置，順序只保留在自己的畫面中，不影響伺服器判定或其他玩家。
3. **手機/平板防誤觸機制**：觸控點擊第 1 下選取卡牌（向上彈起），第 2 下或點擊按鈕確認出牌。
4. **一鍵邀請連結**：支援網址帶房號參數 `?room=8254`，點擊即進房。
5. **化學教學沉澱加番**：難溶鹽沉澱（BaSO₄、CaCO₃ 等）胡牌額外 +5 點，酸鹼中和（H⁺ + OH⁻）額外 +3 點。
